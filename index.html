Two-Stage Disentangled Pipeline

The architecture cleanly separates character facial identity from artistic style and temporal motion:

1. Identity

IP-Adapter decouples cross-attention to preserve facial fidelity and attire directly from the input portrait.

2. Style

Custom LoRA layers on U-Net attention blocks enforce crisp 2D anime/cartoon cel-shading.

3. Motion

AnimateDiff v2 models smooth temporal transitions across 16–24 frames without flickering.
